# Full Moon Client 

**Your Minecraft. Your universe.**

Full Moon Client is a moon-themed client and launcher for Minecraft: Java Edition. It aims to introduce unique, useful, and enjoyable mods while avoiding mods that provide unfair competitive advantages.

Our goal is to create a distinctive Minecraft experience with custom features, a polished launcher, and a visual identity inspired by the Moon.

### Our principles
- **Moon-themed design:** A unique visual identity inspired by the Moon.
- **Unique features:** Custom features and useful mods to enhance gameplay.
- **Fair gameplay:** We aim to avoid mods that provide unfair advantages over other players.
- **A custom launcher:** A dedicated launcher designed for the Full Moon Client experience.
